# My Art Beats

This is the My Art Beats nonprofit site rebuild, built with Next.js 14, TypeScript, and Tailwind CSS for deployment on Vercel.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run linting:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```
